# Что на меня влияет

Прототип ядра гипотезы для Sber500 x Disrupt, трек «Разработаю продукт с нуля».

Человек рассказывает про свой день обычными словами. Мы достаём из рассказа
факты, добавляем данные носимых устройств, ищем повторяющиеся связи и
предлагаем проверить их коротким личным экспериментом.

## Гипотеза

**Проблема.** Состояние скачет — сон, тревога, энергия, головные боли, — а
причины непонятны. Данные разбросаны: кольцо знает пульс и сон, календарь
знает нагрузку, а что вчера был тяжёлый разговор, не знает никто. Приложения
дают обезличенные советы, а дневники, которые могли бы дать ответ,
забрасываются на второй неделе: писать долго и непонятно зачем.

**Гипотеза.** ИИ превращает короткий ежедневный рассказ в исследование
собственной жизни: слушает голосом, сам достаёт события и состояния,
дополняет их данными о сне и активности, находит повторяющиеся связи и
предлагает проверить их экспериментом на самом человеке. На выходе не совет из
интернета, а знание о себе, подтверждённое на своих данных.

## Что уже работает в этом репозитории

Запускается без ключей, сети и регистрации:

```bash
git clone https://github.com/avadkuznetsov-a11y/what-affects-me.git
cd what-affects-me
python3 -m demo.run      # полный цикл на синтетическом дневнике за 90 дней
python3 -m pytest tests -q
```

Вывод демонстрации:

```
«кофе» → «качество сна» на следующий день: хуже на 1.5 балла
        (44 дней с фактором против 45 без, уровень: подтверждено)
«тренировка» → «энергия» в тот же день: лучше на 0.9 балла
        (38 дней с фактором против 52 без, уровень: вероятная связь)
«сладкое» → «энергия»: уровень наблюдение          ← подсадной фактор, связи нет
```

В синтетические данные зашиты две настоящие связи и один фактор-пустышка.
Движок обязан найти первые две и не поднять шум вокруг третьего — на это есть
отдельный тест.

## Как устроено

| Модуль | Что делает |
|---|---|
| `wam/schema.py` | Временная линия: день, факты, факторы, метрики состояния |
| `wam/extract.py` | Рассказ → факты. Правила работают офлайн, модель подключается интерфейсом |
| `wam/wearables.py` | Умное кольцо Sber, Apple Health. Приведение к общей шкале 0–10 |
| `wam/insights.py` | Поиск связей: лаги до 2 дней, перестановочный тест, поправка на множественность |
| `wam/experiments.py` | Личный эксперимент и честный вердикт по итогам |
| `wam/llm.py` | Адаптер GigaChat и заглушка для разработки |

### Три решения, на которых всё держится

**Цифры считает статистика, а не модель.** Языковая модель разбирает речь и
объясняет результат словами, но величину эффекта и его надёжность считает
обычный код. Если позволить модели «оценивать» связи, выводам нельзя доверять,
а доверие тут единственная причина вести дневник дольше недели.

**Поправка на множественные сравнения.** Когда факторов десяток, а метрик
пяток, часть «связей» возникает просто потому, что гипотез много. Без поправки
продукт уверенным тоном выдаёт случайности — и теряет доверие на первом же
выводе, который человек проверит сам.

**Порог наблюдений.** Меньше семи дней в каждой группе — не показываем ничего.
Лучше промолчать, чем сказать красивую глупость.

## Умное кольцо Sber

Кольцо меряет сон, стресс, энергию, пульс и сатурацию, а GigaChat даёт по ним
рекомендации. Чего в этой связке нет — контекста жизни: прибор видит, что
стресс вырос, но не знает, что накануне был перелёт и разговор с руководителем.
Дневник закрывает ровно этот разрыв, поэтому `wam/wearables.py` написан от
кольца: его поля — первые в маппинге, остальные источники приводятся к тому же
формату.

## Приватность

Записи дневника — самые чувствительные данные, какие бывают у человека.
Поэтому: сырой текст хранится зашифрованным, в модель уходит обезличенный
контекст, а расчёт связей полностью локален и не требует отправки данных
наружу. В репозитории нет ни одного ключа, GigaChat читает токен из окружения.

## Статус

Ядро гипотезы, а не готовый продукт. Есть: модель данных, разбор рассказа,
интеграция носимых, движок связей с проверкой на ложные срабатывания,
эксперименты, 16 тестов. Нет: интерфейса, хранилища, авторизации — они делаются
в рамках программы.
