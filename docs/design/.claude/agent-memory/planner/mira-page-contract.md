`web/page.html` - одна страница со скриптом внутри; `web/server.page()` отдаёт её,
подменив три литерала: `__ENGINE__`, `__PERIODS__`, `__DEFAULT_DAYS__` (обычный
`str.replace`, поэтому литералы должны остаться дословно и хотя бы по разу).

**Разметку и скрипт связывают только id.** Скрипт ищет по id: `feed`, `text`,
`mic`, `send`, `micnote`, `sources`, `days`, `sum`, `counting`, ползунки
`sleep`/`stress`/`steps` и подписи к ним `sleepv`/`stressv`/`stepsv`, панель бота
`tg-off`, `tg-on`, `tg-env`, `tg-token`, `tg-name`, `tg-code`, `tg-code-note`,
`tg-code-box`, `tg-linked`, `tg-chats`, `tg-error`. Переименование id ничего не
сломает громко - страница просто молча перестанет что-то показывать.

**Тестов на разметку нет.** `tests/test_web.py` проверяет только HTTP-поведение
сервера, содержимое страницы не читает ни один тест, а `tests/` вообще не знает
про `web/page.html`. **Why:** значит переверстка проходит мимо всего набора
тестов - зелёный pytest ничего не говорит о виде и работе страницы.
**How to apply:** после правок страницы обязателен ручной прогон в браузере
(отправка сообщения, «Показать все выводы», сброс, ползунки, микрофон, панель
Telegram) - зелёные тесты за проверку не считать.

**Классы сообщений в ленте фиксированы сервером:** `me`, `bot`, `ask`, `result`
(значения `kind` из `wam/dialog.py` и `web/server.py`), плюс пометка `from:
"chat"`. Верстка должна оформлять ровно эти четыре, а `white-space: pre-line`
у пузыря обязателен - тексты выводов приходят с переводами строк.

См. [[mira-design-choice]].
