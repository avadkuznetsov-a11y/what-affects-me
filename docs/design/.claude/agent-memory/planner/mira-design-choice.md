Заказчик выбрал вид рабочей страницы: `docs/design/Main.dc.html` («Вариант А -
кабинет», 1280x860) и `docs/design/Mobile.dc.html` («Телефон - по варианту А»,
390x844). Остальные артборды (Warm, Night) отклонены. Пояснения к макетам - в
`docs/design/canvas.json` (поле `annotations`), там же словами сказано, чего
хотели: чат как окно с рамкой и шапкой, справа три блока с границами, «цифр в
шапке нет - только имя и одна фраза», на телефоне панели уезжают в нижние
вкладки, кнопки не мельче 44 px.

**Палитра варианта А:** фон `#eceef1`, текст `#1d2024`, акцент `#3d4f7c`
(наведение `#2b3a5e`), карточка `#ffffff` с рамкой `#c9ced6` и радиусом 10px,
шапка карточки `#f6f7f9` + низ `#d8dce2`, приглушённый текст `#6a7079` /
`#82888f`, разделители `#e4e7eb` / `#eef0f3`. Шрифты в макете - Golos Text
(интерфейс) и Literata (тексты выводов, засечки).

**Запрещено (слова заказчика «всё очень иишное»):** зелёный `#1F8A5B`, эмодзи в
интерфейсе, заголовки капсом вразрядку, жёлто-бежевые плашки-баннеры, цифры-
показатели в шапке.

**Отменено:** прежний запрет на «чат-пузыри как в мессенджере» больше не
действует - выбранный макет построен именно на пузырях (свой - заливка акцентом,
скруглени 12/12/3/12; ответ - серый `#f2f4f6` с рамкой). Радиус тоже вернулся,
но 10-12px, а не 14px на всём подряд.

**Why:** это единственное согласованное решение по виду, и повторно его не
обсуждают. **How to apply:** любые правки вида страницы сверять с этими двумя
файлами, а не придумывать своё; файлы формата Design Components (внутри `<x-dc>`
обычная разметка с инлайновыми стилями, `{{accent}}` - подстановка цвета) и
правке не подлежат - из них только берут.

См. [[mira-page-contract]].
